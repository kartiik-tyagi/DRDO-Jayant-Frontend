# Styling

How colour, type, and layout are applied in this repository. The library underneath Material UI here is Emotion. Pigment CSS is not installed. Do not add a second styling system.

| Chapter | You will be able to |
| --- | --- |
| [Plain CSS](01-plain-css.md) | Read `index.css`, the cascade, and a class name |
| [The `sx` prop](02-sx-prop.md) | Style a MUI component the way the screens do |
| [`styled` and the theme](03-styled-and-theme.md) | Name a reusable styled component and read the theme |
| [Responsive layout](04-responsive-layout.md) | Flex, grid, breakpoints, and a full-height page |

Component-by-component Material UI is [the MUI handbook](../mui/README.md). The theme function for this app is `src/shared/theme/createAppTheme.js`.
